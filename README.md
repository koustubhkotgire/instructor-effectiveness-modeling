# Instructor Effectiveness Modeling

Notebook: `Instructor_Effectiveness_Modeling.ipynb`
Data: `instructor_effectiveness_dataset_2000_rows.xlsx` (keep in the same folder as the notebook)

## Run locally
    pip install -r requirements.txt
    jupyter notebook
Open the notebook, then Kernel -> Restart & Run All.

Libraries used: pandas, numpy, scipy, scikit-learn, matplotlib, seaborn (plus openpyxl to read .xlsx).
No LLMs, external datasets or AutoML. Random seed = 42.
